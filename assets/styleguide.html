Collapse/Expand Functionality

The Go documentation uses a toggle system to show and hide content sections. This is commonly used for code examples, package overviews, and index sections.

Toggle States

  • toggle - Content is collapsed (hidden)
  • toggleVisible - Content is expanded (visible)

Implementation Details

The toggle system uses two CSS classes and JavaScript click handlers:

CSS Classes

.toggle > .collapsed { display: block; }
.toggle > .expanded { display: none; }

.toggleVisible > .collapsed { display: none; }
.toggleVisible > .expanded { display: block; }

.toggleButton { cursor: pointer; }

JavaScript Toggle Function

function bindToggle(el) {
  el.querySelector('.toggleButton').addEventListener('click', function() {
    if (el.classList.contains('toggle')) {
      el.classList.remove('toggle');
      el.classList.add('toggleVisible');
    } else {
      el.classList.remove('toggleVisible');
      el.classList.add('toggle');
    }
  });
}

Usage Patterns

  • Overview sections: Start expanded (toggleVisible)
  • Code examples: Start collapsed (toggle)
  • Index sections: Start expanded (toggleVisible)
  • Arrow indicators: ▹ (collapsed) and ▾ (expanded)
